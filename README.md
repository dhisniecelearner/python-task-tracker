# Python Task Tracker CLI

A simple command-line task tracker built using Python. This project helps users manage their daily tasks through a menu-driven interface.

## Features

- Add new tasks
- Update task descriptions
- Delete tasks
- Mark tasks as `todo`, `in-progress`, or `done`
- View all tasks
- Save tasks in a JSON file so they remain available after restarting the program

## Technologies Used

- Python
- Lists and Dictionaries
- Functions and Loops
- File Handling
- JSON

## How to Run

1. Install Python on your computer.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run the following command:

```bash
python task_tracker.py
```
